# HX-40: A faster MI50 helper head (`DS4_HSTEP_HEAD`, helper-side load/store reordering): no change to one-user decode
Status: dropped (refuted at the predicted size; flag stays off) · Date: 2026-11-16
Code: not in the release commit of Gary, our fork of Strata (internal branch only, on build 17). Flags: `DS4_HSTEP_HEAD=1` (default off).

## What and why
- FG-18 measured that, served, the lead XTX waits for the MI50 helpers for 9–13 % of a one-user step. The helper's head (its first stage, which reads its inputs over PCIe) took about 21 µs of a 75 µs window. FG-18 named this "lever B" and set it as the next build.
- `DS4_HSTEP_HEAD=1` reorders the helper head's loads and stores so that fewer PCIe reads stand at the start of each window. The arithmetic is unchanged, so the output must be identical.

## Prediction
- One-user decode 1–3 % faster. Pre-registered: yes.

## Correctness
- Single-process identity, three configurations (gate 0 switch off, gate 1 and gate 2 switch on): stdout IDENTICAL in each; the switch's log lines were present only where expected (MEASURED).
- Served greedy: both switch-on servers (B1, B2) and the second base server (A2) identical to A1, 8 of 8 requests each (MEASURED).

## Timing
- 16 Nov 09:07. 4 XTX + 4 MI50 helpers (MI50 #1–#4), the 2.25-bit pack. Build 17 (A) against build 17 + `DS4_HSTEP_HEAD=1` (B), served in ABBA order (A1 B1 B2 A2), 4 slots. Cells: one user at 2K and 8K (ms a token, first token), four users (total tok/s and ms a token).

## Verdict
- **No change.** One-user decode moved −0.37 % against a predicted −1 to −3 %, inside about twice the drift. The prediction is refuted at its size. The flag stays off.
- The helper head is not where the lead's wait comes from. Most of a served helper trip is the MI50's expert kernel (HX-36's desk study: about 76 % kernel, 21 % transport, INFERRED). The kernel was the next target (HX-36).

## Reproduce
- Not reproducible from the published code: the switch is not in the public commit.

## Notes / caveats
- The 2K first token moved −1.68 % against 0.60 % drift. The switch acts on the decode helper window, and the cell is one value per server (four values in all), so we do not read this as an effect [I].
- One run a cell per server; two servers an arm.
