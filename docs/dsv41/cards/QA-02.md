# QA-02: The rounding floor: why median KL fails 1e-3 on every TP change
Status: method · Date: 2026-11-08
Code: method. Flags: —.

## What and why
- Any change to summation order (tensor parallel, FP16 all-reduce, tuned GEMMs) moves the logits by a small amount. Compared with a single-group FP32 reference, the median KL sits around 1.6–1.8e-3 for changes that are otherwise harmless, above the original 1e-3 line.

## Prediction
- No prediction was recorded before the run.
- Pre-registered: no.

## Correctness
- tp3 + 3 MI50 vs the same pack run as one layer-split group: top-1 95.84 %, median KL 1.79e-3, ppl 3.3999 → 3.4013, "GATE FAIL" on the KL line (MEASURED).
- Method adopted: compare a change against a common reference with paired block-bootstrap intervals (top-1, median KL, mean KL, ppl); a change passes if every interval of (change − baseline) includes 0 or favours the change [R: method write-up].

## Verdict
- The 1e-3 median-KL line is below this engine's own rounding floor, so later summaries print "GATE FAIL" for changes that pass the paired test. We kept the printed line rather than silently moving it.
