# NX-01: Tensor parallel 2 on two RX 7900 XTX
Status: kept (opt-in) · Date: 2026-11-20
Code: in the fork's `flashnext-amd` commits. Flags: `--tensor-parallel 2` (or `STRATA_TP=2`); in the container, `STRATA_SET="tensor-parallel=2"` with `STRATA_TP_HIP_VISIBLE=<XTX A>,<XTX B>,<MI50s>`.

## What and why
- A layer split over two XTX could not beat one card and plateaued at ~78-81 tok/s aggregate at 4 users. Tensor parallel splits every layer instead: GDN by head group, attention by query heads (12 q / 1 KV head per card), whole experts by owner (expert id modulo 2), and two host-staged all-reduces a layer (each card writes its partial to host-mapped rows, waits for the peer's, sums in member order, so both cards hold identical bits).
- A proof on two XTX came first: all-reduce 11.8 us at 20 KiB; half a GDN layer 0.635x the time; half an attention layer 0.72x; four layers exact.

## Prediction
- Pre-registered: the proof's kill tests (above), all passed. No speed prediction was written for cycle 1.

## Correctness
- 256 / 256 greedy tokens identical to one card; mean top-5 KL 2.4e-4 over all positions (MEASURED). Text sha prefix `4a71bce34308965e` (UD-IQ4_XS), also with the suffix drafter and with the timing build.

## Timing
- Hardware: 2 × RX 7900 XTX 24 GB, 4 × Instinct MI50 16 GB (135 W cap), EPYC 7642 (48 cores), 256 GB DDR4-2666.
- Software: Strata v0.2.9 plus this fork's changes on ROCm 7.2 (the runtime in Strata's ROCm image). Kernel version: not captured in the published extracts.
- Workload: two 2,048-token code generations, engine's own decode rate; UD-IQ4_XS.

## Verdict
- Kept as an opt-in layout. Exact from the first run. Cycle 1 was 0.72-0.85x one card; cycles 2-6 brought it level at one user and ahead at 2-8 users (NX-02, NX-05, NX-06). Its lasting advantage is memory: with the MI50 helpers, every expert sits on a GPU.
- Later timing showed it shortens the dense path by only 6-12 % and pays 2.4-5.3 ms of all-reduce and peer wait a window (ANATOMY.md section 4).

## Reproduce
- Build as in [README.md](../README.md#build); launch "Layout 2" there. The benchmark client is not published.

## Notes / caveats
- Limits under tensor parallel: no MTP drafter, no batched prompt path and no prompt cache (every prompt goes through 8-token decode windows), no vision.
- Cycle 1's spread included rare multi-second windows seen before a host hardware fault that afternoon; none after it.
- Absolute numbers come from a private prompt set (8 prompts, not published); ratios between arms of the same run are the comparable quantity.

Numbers are labelled MEASURED (read from a raw run file or a script-written summary), REPORTED (from a commit message or write-up at the time, not re-checked against raw output), ESTIMATE (our arithmetic) or INFERRED (our own reading).
