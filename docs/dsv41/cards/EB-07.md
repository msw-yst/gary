# EB-07: Four correctness fixes ported from a community MIT project
Status: kept · Date: 2026-11-09
Code: in the fork's release commit (credited in NOTICE). Flags: none (always on).

## What and why
- (1) a memory fence in the worker pool so a sleeping worker cannot miss a wake-up; (2) logits copied on the right stream and sampler errors checked; (3) refuse at load a layer whose experts the CPU lane cannot compute; (4) expert uploads read every NUMA part of a copied expert. A fifth commit narrowed fix 4's DMA path.

## Prediction
- Fixes are for rare races and edge cases; on the test workload the output should not change.
- Pre-registered: yes (identity test plan committed before the run).
- Pass: decode output and logits dump byte-identical to the base build.

## Correctness
- Byte identity of decode stdout (2,048-token prompt, 256 tokens) and of a logits dump (64-token prompt, 8 tokens, 65 rows): IDENTICAL (MEASURED).

## Timing
- Hardware: New layout: 3 × RX 7900 XTX (XTX #1–3, Gen4 x16) + 3 × MI50 32 GB helpers (MI50 #1–3, Gen4 x4 each); every routed expert on a GPU. XTX at minimum power cap with −50 mV. MI50 DPM `auto`.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
- Identity only; the timing lines in the extract are single runs and not a comparison.
