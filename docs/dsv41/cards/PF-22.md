# PF-22: On the 2.25-bit pack, the native pack's RAM-store switch (`DS4_STORE_UNHELD`) costs 5.7 s at 32K; off, the current build reads 32K in 17.8 s
Status: finding (cause confirmed; for the 2.25-bit pack, leave the switch off) · Date: 2026-11-20
Code: not in the release commit of Gary, our fork of Strata (internal branch only). Flags: `DS4_STORE_UNHELD` (PF-19, branch-only, default off); `DS4_PF_HELPER_MAXP=8192` (PF-13, in release 3's recommended environment).

## What and why
- The 2.25-bit before/after run (SV-19) found one regression: the 32K first token went from 18.1 s on the release-3 deployment to 20.9 s on the current engine with the new switches.
- A desk reading of the logs pointed at `DS4_STORE_UNHELD=1`. On the native pack it empties the RAM store of experts the helpers hold, and to stay correct it sets aside the helper's prompt-length cap (PF-13), so every read keeps the MI50 prompt helper. On the 2.25-bit pack the helpers hold every CPU-lane expert, so with the switch on a 32K read goes through the helper instead of the faster XTX path. Below 8,192 tokens both arms use the helper anyway.
- This run removes the new changes one at a time.

## Prediction
- Pre-registered: CONFIRMED if the switch alone adds at least 1.5 s at 32K, no other single change does, and the full new setup without the switch is within 0.5 s of the base.

## Correctness
- Speed-only bisect; every arm CONFIG ok (MEASURED). Drift D2 / D1 × 0.995 (MEASURED).

## Timing
- 20 Nov, the test machine: 4 × RX 7900 XTX (tensor-parallel 4) and MI50 helpers; the 2.25-bit pack. Cold prompts, two 8K controls and two 32K cells an arm.

## Verdict
- **CONFIRMED.** `DS4_STORE_UNHELD` alone explains the 32K loss on the 2.25-bit pack. With it off, the current engine reads 32K in 17.8 s, slightly better than the release-3 deployment's 18.1 s.
- Configuration: the native pack keeps the switch (it is one of STACK's prompt wins there, SV-18); a 2.25-bit configuration leaves it off. A code fix (keep the length cap when every lane expert is helper-held) is possible and not built.

## Reproduce
- No published run: the switch is on an internal branch.

## Notes / caveats
- The size differs between runs: +2.8 s in SV-19's served run, +5.7 s here (cold prompts, a different harness). Both runs agree on direction and cause; we do not know why the size differs.
