# EB-05: Decode stalls: prefault, host memory as GTT, no heap growth, ksmtuned
Status: kept · Date: 2026-11-07 – 2026-11-08
Code: in Gary's release commit. Flags: `DS4_PREFAULT_SPARE` (default 1), `DS4_HOST_GTT` (default 1), `DS4_MALLOC_PIN=1`.

## What and why
- Occasional multi-hundred-ms decode stalls. Chain found: lazily allocated spare RAM parts → transparent-huge-page compaction → userptr MMU notifier → KFD queue eviction. Fixes: make spare parts resident at load, register host memory as GTT not userptr, size buffers at load (no heap growth), pin the heap. The last stall was the OS's ksmtuned walking process memory.

## Prediction
- An integrated test plan expected 0 stalls once each cause was removed.
- Pre-registered: yes (test plan, before the A/B).
