# SV-29: Several users on agent-like 65–77K-token turns (build 12 server): 99 tok/s at 2 users, 144 at 4
Status: finding (inside its predicted ranges) · Date: 2026-11-11
Code: not in the release commit of Gary, our fork of Strata as run (internal branch only: build 12's flags plus the continuous-batching serve loop, later merged into build 13s, SV-10). Flags: build-12 flags; server parallel slots (`PAR`) 1 and 4; drafter on (confidence 0.3, block 3).

## What and why
- The served benchmarks so far used short prompts. Live agent traffic is long continuation turns over a cached history of ~55–75K tokens (SV-08). This run measured one, two and four concurrent agent-like sessions through the batching server, to see what several users get at that context.

## Prediction
- One user alone 10.5–12.5 ms a token; 2 users 96–102 tok/s in all; 4 users 130–148 tok/s in all. Pre-registered: not recorded (the ranges are in the write-up's prediction column).

## Correctness
- Not part of this run. Greedy batched output equal to solo at 9–16-row windows was shown in the same session (DR-07) (REPORTED).

## Timing
- 11 Nov, the 4 XTX + 4 MI50 test machine before the 13 Nov hardware change. Agent-like sessions with ~65–77K-token cached histories (about 99.96 % of each prompt cached), continuation turns of 384 new tokens, sampled (temperature 0.6, top-p 0.95, top-k 20), 3–5 rounds.
- The 4-slot cells ran the server's plain batched path (no drafting inside batched steps).

## Verdict
- **All three predictions held.** At 65–77K context, two users get about 50 tok/s each and four about 36 each, against ~93 tok/s for one user alone.
- One user on the 4-slot server was 13.7 % slower than on the 1-slot server in this run. That looked like a cost of carrying four banks, but a pinned-placement test on 12 Nov showed no bank cost (+0.1 % engine, +0.9 % server, SV-10): the difference here came from a different generated text, not from the slots (INFERRED there).
- The one-user figure (10.73–10.82 ms at ~67K) was the most representative build-12 production number at the time: about 6 % faster than build 11's 11.47 ms on live traffic at ~75K (SV-08) (INFERRED; one session, 3 rounds).

## Reproduce
- No published run: the prompts are agent sessions and are not published.

## Notes / caveats
- One session type, a few rounds per cell; indicative. Other one-user, 1-slot arms in the same run read 10.47–10.92 ms a token (MEASURED).
- Several-user cells had no drafting; with sampled batched drafting at 3 users (build 13s) see DR-07, and later served benchmarks SV-11, SV-14 and SV-17 (short prompts).
