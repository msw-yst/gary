# SV-07: Build 10: fixes + tuned GEMM + one-launch attention + fusions, on tp4
Status: kept (deployed until build 11) · Date: 2026-11-09
Code: in the fork's release commit. Flags: `DS4_HC_FUSE=2 DS4_ROUTE_FUSE=2 DS4_DECODE_TRIM=7 DS4_ROUTER_BF16=1 STRATA_ROCBLAS_TUNING=<table>`; `DS4_MULTI_ATTN` on with batching; `DS4_HELPER_ARMED` off.

## What and why
- Merge EB-07, FG-04, FG-05, FG-02 and HX-09 (off) onto tp4 (TP-05).

## Prediction
- Registered lines: with no new flag set, output IDENTICAL to tp4 and build 9; with the deploy env it may differ.
- Pre-registered: yes (run script).

## Correctness
- Flags unset: IDENTICAL to tp4 and build 9 on tp3h3 and tp4h4, stdout and logits (MEASURED).
- With the deploy env: DIFFER from about token 15. Isolation: fusions + ROUTER_BF16 + pad without the GEMM table are IDENTICAL; the tuned GEMM table alone DIFFERs (FP32 summation order at T=2048) (MEASURED).
- Batched vs solo, cache off: identical 256/256 every sequence (QA-07) (MEASURED). Quality: QA-03.

## Timing
- Hardware: 4 × RX 7900 XTX (XTX #1–3 Gen4 x16, XTX #4 Gen4 x8) + 4 × MI50 32 GB at 135 W (Gen4 x4 each). XTX at minimum power cap with −50 mV. MI50 DPM `auto`.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
- Workload: private 8-prompt decode set (drafter on), batch test B1–B8 (expert cache on), 2K prompt.
- 3 reps, interleaved across arms, fresh process per arm.
- Contamination: a background disk copy (≤ 40 MB/s, idle I/O priority) overlapped every run from the old-tp4 arm's third decode-set rep on; the summary tags each run clean / OVERLAP and flags spreads > 2 %.
