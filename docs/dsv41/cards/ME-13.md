# ME-13: Greedy repeats differ between server starts because expert placement does; pin the placement for every A/B
Status: method · Date: 2026-11-19
Code: not in the release commit of Gary, our fork of Strata (internal native build). Flags: `DS4_CACHE_FREEZE=<n>` (fix the expert placement after n prompt reads) and `DS4_CACHE_DET=1` (the cache's moves land in fixed rounds, so the frozen placement is the same on every start) (branch-only).

## What and why
- QA-08 showed that output depends on which experts sit in VRAM. Through 17–19 Nov, greedy outputs kept failing to repeat within an arm, on builds where nothing should differ: two runs of the same native build (17 Nov), a served greedy identity check that was "uninformative" (FG-20), a gate that failed only on repeat equality (HX-36), and today's prompt runs (1 to 3 of 6–9 cells repeating in PF-17's first run, PF-18 and PF-19).
- Hypothesis: the expert cache moves experts during the warm-up, those moves land in a different order on each server start, so the frozen placement, and with it the arithmetic, differs between starts.

## Prediction
- With moves landing in fixed rounds, every greedy text repeats across server starts, and the placement differs by 0 %.

## Correctness
- This card is about correctness of the method itself.

## Timing
- 19 Nov, the test machine: 4 × RX 7900 XTX + 4 × MI50; native MXFP4 pack. A short-prompt cutoff run (PF-17) with `DS4_CACHE_DET=1` in all six arms (two server starts for each of three settings), 13 cells each.

## Verdict
- **Cause confirmed: placement differing between server starts.** With the moves landing in fixed rounds, the frozen placement repeats, and every greedy text repeats.
- **Rule:** every A/B that compares text or bits runs with the placement frozen and deterministic, and checks placement equality as a gate. Without it, a "bits differ" result says nothing about the switch under test.
- **What it does not cover:** two different binaries can still place experts differently if their code or memory footprints differ (QA-08); check placement equality across arms too (as AR-11 and DR-12 did).
