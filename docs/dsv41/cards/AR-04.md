# AR-04: Prompt all-reduce by peer stores (P2PK), then peer-major order (P2PK2)
Status: kept (opt-in, then default in build 9) · Date: 2026-11-08
Code: in the fork's release commit. Flags: `DS4_AR_P2PK` (default in build 9).

## What and why
- Prompt-chunk all-reduce as a tiled reduce-scatter + all-gather where kernels store straight into peers' VRAM. P2PK2 sends peer-major so one card's stores do not collapse the fabric.

## Prediction
- Abort if the 16K prompt is >10 % slower.
- Pre-registered: yes.

## Correctness
- Self-test bit-identical at load on every start [M: the load line appears in later runs].

- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
