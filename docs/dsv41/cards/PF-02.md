# PF-02: Matrix-core prompt attention with hi+lo FP16 ("f32" mode)
Status: kept (default) · Date: 2026-11-08
Code: in the fork's release commit. Flags: fattn mode `f32` (default on gfx1100 in TP groups); `f16` never default.

## What and why
- Run prompt attention on WMMA with each FP32 operand split into FP16 high and low parts.

## Prediction
- First theory: plain FP16 would be accurate enough. Refuted by real activations (max |q| 83) (REPORTED).
- Pre-registered: no.

## Correctness
- hi+lo passes the paired teacher-forced test (top-1 −0.32 pp, interval [−0.84, +0.18]; median KL −1e-5); plain FP16 fails (REPORTED).

## Timing
- Hardware: New layout: 3 × RX 7900 XTX (XTX #1–3, Gen4 x16) + 3 × MI50 32 GB helpers (MI50 #1–3, Gen4 x4 each); every routed expert on a GPU. XTX at minimum power cap with −50 mV. MI50 DPM `auto`.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
- Reported from notes at the time; the raw runs are not in the published extract.
