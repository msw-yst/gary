# EB-06: Warm-up at load (helper and decode)
Status: kept · Date: 2026-11-07
Code: no switch named `STRATA_DECODE_WARM` is in the fork's release commit (that is the name on the branch measured here). The release commit has the load-time warm-up under `DS4_WARM` (upstream's; `=0` off), `DS4_HELPER_WARM` (its helper rounds, default on) and `DS4_WARM_WAIT` (load waits for it, default 1). Whether they reproduce this card's token-1 result has not been re-measured.

## What and why
- Run the helper's and the decode window's first rounds at load, so the first user token does not pay for lazy initialisation.
