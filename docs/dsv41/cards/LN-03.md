# LN-03: Smaller gate/up jobs on the CPU lane (`DS4_LANEFIX`): the imbalance goes, the time does not
Status: dropped (exact, no gain; flag stays default off) · Date: 2026-11-22
Code: not in the release commit of Gary, our fork of Strata (internal branches only, on release candidate r2a, and a measurement variant). Flags: `DS4_LANEFIX=32|16` (gate/up jobs of 32 or 16 rows instead of 64; default off).

## What and why
- LN-01 put 26.6 µs of the lane's 45.9 µs fixed cost per call in gate/up thread imbalance: with 64-row jobs some lane threads idle while others finish. Splitting into 32- or 16-row jobs should remove the idle tail.

## Prediction
- Pre-registered: yes. −0.06 to −0.23 ms a token (−0.13 / −0.15 central for 32 / 16).

## Correctness
- EXACT PASS: 4,000 token ids identical across the off, 32 and 16 blocks and the stamped arm (MEASURED). Exact by construction (same per-row arithmetic).

## Timing
- 22 Nov, the test machine (four XTX + five MI50 helpers), native MXFP4 pack, BF16 matvec on, fixed placement, single user, drafter off, greedy, 2K prompt; off / 32 / 16 run as blocks in one process.

## Results
| item | off (64) | 32 | 16 | label |
|---|---|---|---|---|
| gate/up imbalance per one-expert call | 22.4 µs | 9.4 µs | 5.3 µs | MEASURED |
| fixed cost per call (intercept) | 45.4 µs | 28.4 µs | 27.6 µs | MEASURED |
| cost per expert (slope) | 171.3 µs | 180.9 µs | 186.8 µs | MEASURED |
| decode vs off | — | **+0.030 ms** (noise 0.070) | **+0.190 ms** (noise 0.079) | MEASURED |
| calls engaged | — | 19,587 | 19,600 | MEASURED |

## Verdict
- **The fix works as designed but buys no decode time.** Smaller jobs cost more per expert (more scheduling, less cache reuse), which eats the saving at 32 rows and loses outright at 16. This lane option is closed.
- By-product: the GPU eviction reader now works (all arms CLEAN), which was needed for the freeze work (HW-17, HW-18).

## Reproduce
- No published run: the code is not in the release commit.

## Notes / caveats
- The off arm's server start took a 107.9 s eviction at load (prompt read 22.2 s against ~9.9 normal); decode cells were unaffected (MEASURED; HW-17).
- The bench text loops after token 549 (LN-01); the per-call imbalance is not sensitive to that, the token-time result may be.
