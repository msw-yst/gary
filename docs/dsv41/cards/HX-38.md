# HX-38: An MI50 kernel for windows of two or more tokens (`DS4_MXW_MT`): faster on the bench, neutral served; a four-user gain we first reported is withdrawn
Status: finding (exact and harmless, served-neutral; correction: the four-user × 1.065 was an outlier) · Date: 2026-11-20
Code: not in the release commit of Gary, our fork of Strata (internal branch only). Flags: `DS4_MXW_MT=1` (branch-only, default off).

## What and why
- When a helper window carries two or more tokens (drafter verify rows, several users), the MI50's MXFP4 expert kernel left its fast path: a grid limit sent T ≥ 2 to the slow general kernel.
- `DS4_MXW_MT=1` gives T ≥ 2 its own kernel: no staging through local memory, and the smallest instance count that covers T, up to 16. It is exact by construction (the same arithmetic in the same order per token).

## Prediction
- Bench: faster at T = 2–16. Served: a gain where windows carry several tokens (four users, drafting). No served size was pre-registered beyond "no harm".

## Correctness
- Served identity with the flag on and off: 8 of 8 (MEASURED).

## Timing
- 20 Nov, the test machine: 4 × RX 7900 XTX (tensor-parallel 4) and 5 × MI50 32 GB helpers at 135 W (HX-37); native MXFP4 pack. Kernel bench on one MI50; served A/B D (flag off) against M (flag on), interleaved D1 M1 M2 D2, drafting at block 3.

- **The correction.** The four-user gain came from one rep: D2's first four-user rep read 72.1 tok/s, while every other four-user rep in the run read 98.0–102.8. The same arm's 8K four-user first token was 11.55 s against about 7.3 s elsewhere, so D2 had a transient stall. That one low baseline rep made the flag look 6.5 % faster. Without it the flag is within 1 % at every user count (MEASURED).

## Verdict
- **Served-neutral.** The kernel is faster on the bench, but at the window sizes served today (block-3 drafting, up to four users) the time it saves is too small a share of a decode step to show.
- **Do not cite the four-user + 6.5 %.** We reported it in our notes before checking the per-rep lines; it is withdrawn here.
- It may matter for larger windows (block 6 drafting, DR-14, lands windows near T = 16, where the bench gain is largest) (INFERRED). The kernel stays available, default off.
