# NX-02: Batching under tensor parallel, with device-planned expert dispatch
Status: kept · Date: 2026-11-20
Code: in the fork's `flashnext-amd` commits. Flags: `--batch N` (the container's `PARALLEL`), with `--tensor-parallel 2`.

## What and why
- One batch window carries one row per active slot. Under tensor parallel each card plans its own experts on the GPU; card 1 never needs the host (its graph has no host waits except PLE), and card 0 skips the host for layer-steps whose experts are all on the two XTX.

## Prediction
- No numeric prediction was recorded before the run.
- Pre-registered: no.

## Correctness
- Batched == solo for every prompt at 2, 4 and 8 users once the presence penalty is set to 0 (batched requests then skipped it; fixed later, NX-08) (MEASURED).

## Timing
- Hardware: 2 × RX 7900 XTX 24 GB, 4 × Instinct MI50 16 GB (135 W cap), EPYC 7642 (48 cores), 256 GB DDR4-2666.
- Software: Strata v0.2.9 plus this fork's changes on ROCm 7.2 (the runtime in Strata's ROCm image). Kernel version: not captured in the published extracts.
- Workload: 8 prompts × 384 tokens, temperature 0, presence penalty 0, 1/2/4/8 users; UD-IQ4_XS.
