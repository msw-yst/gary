# TP-05: tp4: four XTX, uneven expert split; 2×2 grid tp3/tp4 × 3/4 helpers
Status: kept · Date: 2026-11-09
Code: in the fork's release commit (uneven-split approach ported from a community MIT project, credited in NOTICE). Flags: `--tp 4`, `DS4_TP_CHECK=1` (load-time part check).

## What and why
- A head-split bug for 4 members was fixed, then routed experts split unevenly in whole blocks over four XTX. Grid: tp3 or tp4, with 3 or 4 MI50 helpers.

## Prediction
- Pre-registered pass line: decode-set gain with B8 and 16K prefill not worse than allowed by the run script's header.
- Pre-registered: yes (run script header, committed before the grid).
- The script printed PASS/FAIL per arm against tp3h3 (see `timing.txt`).

## Correctness
- Regression: flags-off output IDENTICAL to the previous build (REPORTED).
- Quality of tp4: 95.96 % top-1 against the reference (REPORTED).
- Batched-vs-solo in this grid ran with the expert cache on and differs from token 1 or later (rc 3); SV-07 later showed that with the cache off every sequence is identical, so this is cache placement drift, not a batching bug [M, see SV-07].

## Timing
- Hardware: 4 × RX 7900 XTX (XTX #1–3 Gen4 x16, XTX #4 Gen4 x8) + 4 × MI50 32 GB at 135 W (Gen4 x4 each). XTX at minimum power cap with −50 mV. MI50 DPM `auto`.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
- Workload: private 8-prompt decode set (ME-01), batch test B1–B8 (1,024-token prompts, N 256), 2K and 16K prompts.
- 3 reps, interleaved across the four arms; fresh process per arm. MI50 DPM `auto`.

## Verdict
- Decode held (+9.9 %); B8 −5.1 % and 2K prompt +10.7 % slower. tp4h4 became the decode layout; the prefill cost was traced later to the slowest member (PF-09).

## Reproduce
- Fork release commit; launch each layout with `tools/dsv41/devmap.sh` for the device order (as `docs/examples/dsv41-serve.sh` does). The grid script used for this card is not included in the release. Original grid ~190 GPU-min; a reduced tp3h3 vs tp4h4 re-run ~60 GPU-min.
