# HX-09: Armed helper windows
Status: kept (opt-in, default off) · Date: 2026-11-09
Code: in the fork's release commit. Flags: `DS4_HELPER_ARMED=1` (default off).

## What and why
- Arm each MI50's next window before the XTX needs it, so the helper is already waiting for the request.

## Prediction
- Pass lines in the run script.
- Pre-registered: yes (run script).

- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
