# NX-13: CPU pool workers sleep between layers (predicted wake)
Status: kept (opt-in; proposed default for one server per machine) · Date: 2026-11-21
Code: in the fork's `flashnext-amd` commits. Flags: `STRATA_POOL_WAIT=pred` (Linux); `STRATA_POOL_PRED_MARGIN_US` (default 30); `futex` and `nap` modes kept for comparison.

## What and why
- A one-card server's CPU pool (31 workers here) spun at 100 % from the first token at every load, yet was idle 77-87 % of the time at 1 user and 56-60 % at 8: a layer is two short phases, then ~300-850 us of nothing while the GPU runs the dense part.
- `pred`: after each layer's last phase the host posts an absolute wake time = now + the smallest gap this same layer had in the last 4 windows - 30 us. Workers nap to it (timed futex, 1 us timer slack), spin at most 200 us past it, then block. Inside a layer the post says "now". A parked worker keeps spinning until the post for its phase lands.

## Prediction
- Fewer busy cores at no loss in tok/s.
- Pre-registered: not recorded in the published extracts.

## Correctness
- Scheduling only: the tasks are the same fixed row ranges, claimed dynamically, so no output bit can change. Measured: reference hashes unchanged, batched == solo 8/8, and every streamed text of every speed level identical between spin and pred in all runs (MEASURED).

## Timing
- Hardware: 2 × RX 7900 XTX 24 GB, 4 × Instinct MI50 16 GB (135 W cap), EPYC 7642 (48 cores), 256 GB DDR4-2666.
- Software: Strata v0.2.9 plus this fork's changes on ROCm 7.2 (the runtime in Strata's ROCm image). Kernel version: not captured in the published extracts.
- Workload: 8 prompts × 384 tokens, temperature 0; one server at a time, two alternating runs per arm; S = one XTX + 2 MI50, SM = S + MTP, S2 = two such servers side by side.

## Verdict
- Kept. For one server per machine it is exact, no slower and frees 17-20 cores and 10-14 W. For two servers per machine it is within 1 % but not proven no-slower (server 1 was 2 % lower in every pair), so it stays opt-in. Used on the shared-pool workers.

## Reproduce
- "Layout 1" in [README.md](../README.md#launch) with and without `STRATA_POOL_WAIT=pred`.

## Notes / caveats
- Screened and not kept: `futex` (-1.5 to -3 %: one wake-all of ~25 sleepers starts the last worker 27-146 us late), `nap` (about even, 15-18 cores), a wake fan-out tree (worse).
- An unrelated compile job ran during one pred run's 4- and 8-user levels; the clean pair is quoted beside it.
- Run-to-run spread is about 1 %.
- Absolute numbers come from a private prompt set (8 prompts, not published); ratios between arms of the same run are the comparable quantity.

Numbers are labelled MEASURED (read from a raw run file or a script-written summary), REPORTED (from a commit message or write-up at the time, not re-checked against raw output), ESTIMATE (our arithmetic) or INFERRED (our own reading).
