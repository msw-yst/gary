# FG-11: The many-workgroup top-k for batched decode (`DS4_TOPK_MB_BATCH`)
Status: kept (build 15) · Date: 2026-11-13
Code: in the fork's release commit. Flags: `DS4_TOPK_MB_BATCH=1` (default off; on in build 15's environment).

## What and why
- `DS4_TOPK_MB` (FG-10) speeds the indexer's top-k for one sequence. Batched decode (several users at once, SV-03) runs the indexer through a different, per-bank path that still used the one-workgroup top-k, so at long context every user paid the old cost on every step.
- This flag gives the batched path the same multi-workgroup top-k.

## Prediction
- ms a batch step (= each user's ms a token in a plain step), on − off: 64K, 4 users −0.95 [−1.20, −0.60] (primary); 64K, 2 users −0.48 [−0.60, −0.30]; 110K, 2 users −0.79 [−1.00, −0.50]. Single-sequence guard at 64K and 110K: no change. Pre-registered: yes, in the run's prereg, before the run.

## Correctness
- 3 identity lines IDENTICAL: unset vs the base build; on vs off on the batch test at short context and at 32K (MEASURED). In every timing run each batched output was identical to its solo greedy output.

## Timing
- Hardware: after the 13 Nov hardware change: XTX #2 is a replacement board and XTX #4 runs its board's second firmware position (HW-09); otherwise as in FG-10.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes (build 14 plus the flag).
- Batch test, greedy, drafter off; OFF / ON / placebo, 3 rounds at 64K and 2 at 110K.

## Verdict
- **−3.5 % a step at 64K with 4 users and −3.9 % at 110K with 2, exact.** All three results are within 7 % of their central prediction. Kept; on in build 15.
- It engages only from about 32K tokens of context, so short-prompt multi-user benchmarks will not show it (REPORTED from the build-15 proposal).

## Reproduce
- No published run: the code is in the release commit; a scripted public re-run has not been prepared for this card.

## Notes / caveats
- The 4-user noise floor (0.504 ms) comes from the placebo arm, which ran 0.38 ms slower than off; the gain is still beyond it.
