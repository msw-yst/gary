Status: kept (pass on the paired test) · Date: 2026-11-09
Code: in the fork's release commit. Flags: build-10 deploy env.

## What and why
- Build 10 is not byte-identical to build 9 (the tuned rocBLAS table changes summation order, FG-04), so it needed a quality comparison.

## Prediction
- Paired test: every interval of (tp4h4 − tp3h3) vs the reference includes 0.
- Pre-registered: yes (run script).

## Correctness
- Reference: the same 2.25 bpw pack run as one layer-split group (not a higher-precision model).
