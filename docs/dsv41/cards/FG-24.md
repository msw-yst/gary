# FG-24: Batched GPU sampling for concurrent users (`DS4_GSAMP`): exact, 3.2× cheaper per window, no served gain
Status: dropped (not adopted) · Date: 2026-11-18
Code: not in the release commit of Gary, our fork of Strata (internal branch only). Flags: `DS4_GSAMP` (branch-only, default off).

## What and why
- With four users, the host samples each user's row in turn; the trace read in FG-21 put the host sampler at about 10 ms a 4-user step (traced), and the lever list predicted 5–7 ms a step (+12–18 % at 4 users) from sampling all rows in one GPU call.

## Prediction
- 4 users × ≥ 1.05 (the GO bar), from the 5–7 ms estimate.

## Correctness
- Unit test PASS; the batched sampler is 3.2× cheaper per window in the unit test (267 against 863 µs for 4 sampled rows); seeded sampled sequences identical; an in-engine cross-check found 0 mismatches over 4,934 rows (MEASURED).
- First served run: stopped at the bits gate: greedy outputs differed on 3 of 3 prompts, in the switch-off comparison against the base build too, so the gate itself was suspect. Second run, corrected gate and a warmed harness: **BITS PASS**, greedy 6 of 6, 24 sampled sequences and 600 of 600 seeds identical (MEASURED).

## Timing
- 18 Nov, the test machine: 4 × RX 7900 XTX + 4 × MI50; native MXFP4 pack, internal native build. Served A/B with the switch off and on (O S S2 O2).

## Results

## Verdict
- **Not adopted.** Output identical, the sampler much cheaper in isolation, but no measurable gain at four users: host sampling is not the 4-user bottleneck on this build that the trace suggested.
- The second run first seemed to show the new binary 1.36× slower than the base even with the switch off. That was a passive sampler started beside the run, not the binary: inside the base arm itself, 4 users fell from 79.0 to 62.6 tok/s when it started (ME-15). The off-on comparison (× 1.005) ran under the same sampler in both arms and stands.

## Reproduce
- No published run: the code is on an internal branch.

## Notes / caveats
- The 10 ms was a traced figure, and tracers inflate time (ME-06). The unit-test saving, about 0.6 ms a window, is invisible at four users (INFERRED).
