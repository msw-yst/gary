# CP-05: MI50 power cap 155 W and 178 W instead of 135 W
Status: dropped (caps stay at 135 W) · Date: 2026-11-13
Code: not applicable. Flags: host power caps (hwmon), restored to 135 W after the run.

## What and why
- The MI50s run capped at 135 W. Telemetry showed them at the cap for 15–21 % of prompt time but only 3.3 % of served decode time (MEASURED, below), so a higher cap could only help prompts. This run measured how much.

## Prediction
- Decode (served mix and B1): no change, ±0.05 ms (the "free" prediction set, chosen because decode is rarely at the cap).
- Prompts (the "capped" set): 178 W −1.9 % at 8K, −1.4 % at 32K, −0.3 % at 110K (ranges in the extract); 155 W smaller. Pre-registered: yes, with the rule that picks the prediction set from the base arm's at-cap share.

## Correctness
- 4 identity lines IDENTICAL (MEASURED); a power cap does not change arithmetic.

## Timing
- Hardware: 4 × RX 7900 XTX (XTX #1–3 Gen4 x16, XTX #4 Gen4 x8) + 4 × MI50 32 GB (Gen4 x4 each). XTX at minimum power cap with −50 mV. MI50 DPM `high` (CP-03). 13 Nov 07:29.
- Software: build 13 with the served and deploy environment. Arms 135 W (base), 155 W, 178 W and a 135 W placebo; 4 reps of decode, 2 of prompts.

## Results
| measure | 155 W vs 135 W | 178 W vs 135 W | label | data |
|---|---|---|---|---|
| served mix, ms a generated token (base 9.890) | +0.17 % | +0.33 % (noise 0.13 ms) | MEASURED | power-cap-ab.txt |
| B1, ms a token (base 13.605) | −0.06 % | +0.09 % | MEASURED | power-cap-ab.txt |
| prompt 8K | −1.37 % | −2.15 % (placebo +7.97 %, over its bound: not separable) | MEASURED | power-cap-ab.txt |
| prompt 32K | −1.04 % | **−2.78 %** | MEASURED | power-cap-ab.txt |
| prompt 110K | −0.51 % | **−2.39 %** (noise 0.46 %) | MEASURED | power-cap-ab.txt |
| max MI50 junction | 70 °C | 73 °C | MEASURED | power-cap-ab.txt |

## Verdict
- **178 W makes long prompts 2.4–2.8 % faster and does nothing for decode or served tokens; 155 W is not separable anywhere.** The 110K gain beat its prediction (−0.30 %).
- Cost: +43 W a card, about +170 W for four, for a small prompt-only gain. **The caps stay at 135 W.**

## Reproduce
- Write `power1_cap` for each MI50 under `/sys/class/drm/card*/device/hwmon/`, then run any prompt-timing harness with interleaved arms.

## Notes / caveats
- The first attempt was refused before any GPU work: on this kernel the MI50's hwmon exposes `power1_input`, not `power1_average`. The script was fixed and rerun.
