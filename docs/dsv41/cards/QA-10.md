# QA-10: Engine parity with upstream Strata and llama.cpp at the same weights (VANILLA): ENGINE PASS
Status: kept (method; pre-registered verdict PASS) · Date: 2026-11-16
Code: build 17, in the fork's release commit (release 3), against upstream Strata v0.2.9 and llama.cpp b11870. Tools: `validation/engine-parity/` (summariser, logit filter, prompt selection, llama.cpp reference client) and `validation/engine-parity/strata-dsv41/` (the Strata arm script, the FREE driver, the RENDER step, the pre-registration).

## What and why
- Every change in this fork was gated for byte identity or a paired quality test against its predecessor. This asks the end-to-end question once: at identical weights and identical prompt ids, does build 17 compute what upstream Strata computes, and how far are both from an independent engine?
- Arms: **L** llama.cpp b11870 (the reference: greedy 256 tokens with the top-20 at every position); **V** upstream Strata v0.2.9, its native configuration; **P1** this fork's build 17 binary with build 17's recommended engine flags. All three on one RX 7900 XTX with the routed experts in host RAM, drafting off; the same 2.25 bpw IQ2_XS weights (llama.cpp reads them after a byte-for-byte layout conversion with the quant author's own converter).

## Prediction
- Pre-registered before any data (`validation/engine-parity/strata-dsv41/prereg.md` §5): **ENGINE PASS** if e_P1 − e_V ≤ max(0.10 × e_V, 0.002) nats a token and top-1 agreement a_P1 − a_V ≥ −0.005, where e and a are the teacher-forced KL from L and the top-1 agreement with L. NO DATA if either arm misses more than 2 of the 12 prompts.

## Correctness
- This card is a correctness check. Inputs: 40 real agent request bodies (private), rendered by build 17's own server into the exact ids every arm reads; 12 chosen by L's results only (3 per length band: 2–8K, 8–20K, 20–40K, 40–70K tokens).
- **TF (teacher-forced):** each engine reads prompt + L's 256 greedy tokens in one pass and dumps its logits; the distributions over L's continuation are compared with L's top-20 (KL over L's top-20 plus a rest bucket, masses floored at 1e-6; an approximation, not a bound).
- **FREE:** each engine's own greedy 256 tokens on all 40 prompts, compared with L's.

## Timing
- 15–16 Nov, one RX 7900 XTX with host-RAM experts (not the 4 XTX + 4 MI50 test machine). Not a timing run.

## Verdict
- **ENGINE PASS (pre-registered rule): build 17 computes what upstream Strata computes.** The difference from upstream (+0.00003 nats, −0.49 points top-1) is inside both floors; there is no length-band trend.
- **Both Strata engines sit about 0.004 nats a token from llama.cpp**, 97 % top-1. No placebo exists for that pair, so it is reported, not judged. For scale, the 2.25-bit weights sit about 0.044 nats from the hosted model (QA-11): ten times further.
- Free-running text diverges from llama.cpp after a median of 18–21 tokens in both Strata arms alike: near-ties resolving differently in GPU arithmetic, not errors (INFERRED from the TF numbers).
- Top-1 −0.49 points is close to its 0.5 floor; KL, the primary measure, is far inside its floor.
