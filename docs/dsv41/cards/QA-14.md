# QA-14: A loop guard for agent runs on the 2.25-bit pack: it detects loops, but its nudge does not rescue them
Status: finding (2.25-bit stays off the table for agent work) · Date: 2026-11-17
Code: not in the release commit of Gary, our fork of Strata (a guard in our private agent harness). Measurement: agent coding tasks, served on the 2.25-bit pack.

## What and why
- On long agent tasks the 2.25-bit pack passes less often than the native pack, partly because it circles: it repeats steps until the time or token budget runs out. A guard that detects circling and sends a nudge might close part of the gap within about twice the tokens.

## Prediction
- Headline, pre-registered: the 2.25-bit pack with the guard reaches the native pack's pass rate on the same tasks.

## Correctness
- Not an engine change. The guard's false triggers and cost were counted.

## Timing
- 17 Nov, the 4 XTX + 4 MI50 test machine; the 2.25-bit pack; two tasks, three attempts each, the guard active (the second half of a larger run).

## Results
| measure | value | label |
|---|---|---|
| passes with the guard, 2.25-bit | 2 of 6 (one task 2 of 3, the other 0 of 3) | REPORTED |
| the native pack on the same tasks | 4 of 6 | REPORTED |
| loops caught / false triggers / rescues | 1 of 1 / 0 / **0** | REPORTED |
| time saved / guard cost | 0 min / 98 s in all | REPORTED |

- Neither pass came from the guard: one attempt never circled, one recovered on its own. The one nudged attempt kept circling and timed out at 256K tokens, like the attempt without a guard. The other task fails fast and confidently wrong (5–14 minutes), outside what a loop guard can see (REPORTED).

## Verdict
- **Headline NOT met.** Detection works (1 of 1, no false triggers); the generic nudge does not rescue. The 2.25-bit pack stays off the table for agent work.
- Next for the guard: specific nudges based on what the run is repeating, and escalation, tested on a build worth rescuing.

## Reproduce
- No published harness.

## Notes / caveats
- Six attempts in all; one attempt run at the wrong guard setting was excluded and repeated, and the classification was not blinded (both recorded as deviations at the time).
- In the same week the native pack scored 4 of 7 overall on the harder task set; one long native attempt failed after 176 minutes (REPORTED).
