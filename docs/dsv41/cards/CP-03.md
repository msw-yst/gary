# CP-03: MI50 DPM `high` (clock pin)
Status: kept (via launch wrapper) · Date: 2026-11-10
Code: launch wrapper in Gary's release commit. Flags: host sysfs `power_dpm_force_performance_level=high`.

## What and why
- Set the MI50s to DPM `high` instead of `auto`, so the core and memory clocks do not ramp per helper request.
- Target slice: the helper window's ramp-up at low duty cycle; at idle the MI50s sat at 938 MHz core / 350 MHz memory (MEASURED).

## Prediction
- No prediction was recorded before the run.
- Pre-registered: no.

## Correctness
- Decode stdout IDENTICAL before and after (MEASURED).

## Timing
- Hardware: 4 × RX 7900 XTX (XTX #1–3 Gen4 x16, XTX #4 Gen4 x8) + 4 × MI50 32 GB at 135 W (Gen4 x4 each). XTX at minimum power cap with −50 mV. MI50 DPM `auto`.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus Gary's changes. Kernel version: not captured in the published extracts.
- 1 run before and after, B1 tp4h4, untraced.
