# HX-17: Device-direct helper windows v2
Status: kept (opt-in; part of build 11) · Date: 2026-11-10
Code: in Gary's release commit. Flags: `DS4_HELPER_DD=1` (default off).

## What and why
- After each layer, every MI50's window for the next layer is armed. Each MI50 waits on the device for its request, runs the layer, and writes a flag. The lead XTX waits for and joins the rows in one fused kernel. This takes the host's per-layer issue and join off the critical path.
- Target slice: the lead waited 3.5 ms of an 18.7 ms single-stream token and 23.3 ms of a 53.3 ms 8-stream step [M, HX-14].

## Prediction
- Desk estimate in the helper-chain design note, committed before the code: B1 −1.5 to −2.0 ms; B8 −4 to −6 ms; exact by construction.
- Pre-registered: yes (design note committed at 12:41, refined 13:03; code at 13:39).
- Gate: byte identity, or the run stops.

## Correctness
- Decode (N 256), batch test (B 1/2/8, drafter on) and window-16 teacher-forced score, all against flags off.
- 4 XTX + 4 MI50: decode and batch IDENTICAL; score not run (MEASURED).
- 3 XTX + 3 MI50: decode, batch and score IDENTICAL (MEASURED).
- 9,945 requests joined on the device, 0 host fallbacks (MEASURED).

## Timing
- Hardware: 4 × RX 7900 XTX (XTX #1–3 Gen4 x16, XTX #4 Gen4 x8) + 4 × MI50 32 GB at 135 W (Gen4 x4 each). XTX at minimum power cap with −50 mV. MI50 DPM `high` (CP-03).
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus Gary's changes. Kernel version: not captured in the published extracts.
- Workload: private prompt set, 8 × 1,024 tokens, solo + B1 + B8, N 256, expert cache off, ctx 8192.
- 3 reps, order forward / reverse / forward, fresh process per arm. MI50 DPM `high`.

## Verdict
- Wrong on size: −0.63 ms against −1.5 to −2.0 ms at B1; −1.87 ms against −4 to −6 ms at B8. The host wait fell from 2.7 to 0.1 ms, but most of that time reappeared on the lead: it now waits for every MI50 in all 39 layers, including MI50s with no pick that layer. The delay sweep's slope (about 1 ms of step per 50 µs of helper delay) shows the lead is directly exposed (MEASURED).
- Kept, because it is exact and faster. The finding led directly to HX-18.

## Reproduce
- Gary's release commit; identity, batch-test and sweep phases with `DS4_HELPER_OVERLAP=1 DS4_HELPER_BATCH=1 DS4_HELPER_DD=1` on and off. The A/B script used for this card is not included in the release. About 50 GPU-min (INFERRED).

## Notes / caveats
- The 4-XTX score identity was not run (about 5 GPU-min to fill).
- DD processes read more from disk than AB (about 75 vs 59 GB per process), unexplained.
- B8 shows process-level bimodality.
- Absolute numbers come from a private prompt set (not published); a re-run on a public text is pending. Ratios between arms of the same run are the comparable quantity.
- Headline card: a public-text re-run is planned (about 50 GPU-min).
