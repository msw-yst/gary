# NX-08: Penalties applied in batch windows
Status: kept (default) · Date: 2026-11-21
Code: in the fork's `flashnext-amd` commits. Flags: none (default path).

## What and why
- Batched requests skipped every penalty: `sample_rows` passed no history and set `penalty_last_n = 0`, so they lost the model card's presence penalty (1.5) and any penalty in the request body, and a batched answer differed from the same request alone. The batch loop now stages one history row per window row (the slot's consumed tokens plus its fed token or proposal) and samples penalised rows exactly as the solo window does.

## Prediction
- Expected batched == solo with penalties on, at no measurable cost.
- Pre-registered: not recorded in the published extracts.

## Correctness
- Batched == solo with penalties on: before 0/8 on one card and tp2, after 8/8 (and 4/4) on one card, tp2 and one card with MTP (the MTP arm was measured only after), for temperature 0 + presence 1.5, the full model-card set (temperature 0.7, top_p 0.8, top_k 20, presence 1.5, seeded) and body overrides (presence, frequency, repetition, penalty_last_n). Solo texts unchanged (MEASURED).

## Timing
- Hardware: 2 × RX 7900 XTX 24 GB, 4 × Instinct MI50 16 GB (135 W cap), EPYC 7642 (48 cores), 256 GB DDR4-2666.
- Software: Strata v0.2.9 plus this fork's changes on ROCm 7.2 (the runtime in Strata's ROCm image). Kernel version: not captured in the published extracts.
- Workload: 8 prompts × 384 tokens; one server at a time.

## Verdict

## Reproduce
- Any layout with `PARALLEL` > 1; compare a batched request's text with the same request alone.

## Notes / caveats
- `logit_bias` is refused under `--batch` (unchanged).
- With penalties on, tp2's solo text differs from one card's (equal at presence 0). Pre-existing; not investigated.
- Absolute numbers come from a private prompt set (8 prompts, not published); ratios between arms of the same run are the comparable quantity.
