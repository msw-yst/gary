## What and why
- Baseline from a mainstream engine on the same box: the older DeepSeek V4-Flash-0731 UD-Q8_K_XL with experts on the CPU, then a layer split adding the MI50.
- Target slice: establish what an unmodified engine gets from adding an MI50 by layer split.

## Verdict
- Adding the MI50 by layer split made decode 7 % slower in this configuration. A different model file (Q8 of an older Flash) and a different engine, so not a like-for-like baseline for the Strata numbers.
- A second control on the later 3 XTX + 3 MI50 layout was prepared on 8 Nov but never run.
