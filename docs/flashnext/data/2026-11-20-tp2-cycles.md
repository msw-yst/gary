# Tensor parallel 2: the six cycles of 20 November 2026 (data extract)

Sanitised extract of the run summaries behind [JOURNEY.md](../JOURNEY.md) and cards NX-01 to NX-07. The originals are kept
privately. Hardware: 2 x RX 7900 XTX 24 GB ("XTX A" = tensor-parallel card 0, "XTX B" = card 1), 4 x Instinct MI50 16 GB
(MI50 #1-#4; #3 is the slow-link card), EPYC 7642, 256 GB DDR4-2666. Model: Qwen3.8 Flash-Next.

Client for every speed row unless stated: 8 fixed prompts, 384 tokens each, temperature 0, presence_penalty 0; c = 1
(each prompt alone, the solo path), 2, 4, 8 users. "agg" = aggregate tok/s over the wall clock; "all-active" = aggregate while
every stream is running; "per user" = median over users of streamed chunks per second.

## Step 1: exactness and one-user speed (UD-IQ4_XS)

- Exactness: tp2 vs one card, fixed code prompt, temperature 0, 256 tokens, top-5 logprobs: **256 / 256 tokens identical**, mean
  top-5 KL 2.4e-4 over all positions. Text sha256 prefix `4a71bce34308965e` (also with the suffix drafter and with the timing
  build).
- Decode, engine's own rate on two 2,048-token code generations: one card 46.4-48.4 tok/s; tp2 27.4-40.8 tok/s (0.72-0.85x).
  tp2 read a 1,631-token re-read through 8-token verify windows (19-25 s); one card reused it from its prompt cache in 0.2 s.
- VRAM after load: card 0 23.08 GiB, card 1 21.89 GiB of 23.98. Experts in VRAM: 8,281 + 7,211 = 63 % of 24,576 (one card: ~26 %).

## Fair round: tp2 + 4 MI50 (one server) vs two one-card servers (1 XTX + 2 MI50 each)

Same session, arms alternated A B A B; Q4_K; no MTP on either arm. B: XTX A + MI50 #1, #2 and XTX B + MI50 #3, #4,
`PARALLEL=4` each, the same fast helper transport, no CPU shared between the servers. B's fill: 16,474 and 16,012 of 24,576
on GPUs (CPU path 8,102 / 8,564). Host RAM with both B servers up: 190 GB of 251 (A: ~119).

Exactness: Q4_K reference sha `a7ae6623797f17fe` (256-token solo) on A and on both B servers; batched == solo 14/14 on every

and a different set of experts on each server's CPU path).

This round is why the shared MI50 pool was built ([SHARED-POOL.md](../SHARED-POOL.md)): two one-card servers beat tp2 at 2-8
users, but each keeps about a third of the experts on the CPU.
