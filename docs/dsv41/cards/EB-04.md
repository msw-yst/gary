# EB-04: Multi-GPU "invalid kernel file" with ROCm 7.14: all-arch build
Status: kept · Date: 2026-11-07
Code: in the fork's release commit. Flags: `STRATA_HIP_HELPER_ALLTU=1` (build).

## What and why
- The first 3-XTX layer-split run hung with "invalid kernel file". Root cause: with ROCm 7.14 every HIP translation unit must carry every architecture present in the process; the helper archs were only in some.

## Prediction
- No prediction was recorded before the run.
- Pre-registered: no.

## Correctness
- A diagnostic script reproduced and then cleared the failure (REPORTED). Not re-run since.

## Timing
- Hardware: Early layout: up to 3 × RX 7900 XTX plus host-RAM experts on the CPU lane, 1–3 × MI50 32 GB helpers. EPYC Zen 2 16-core, DDR4-2666. Stock XTX power settings.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
- 1 run per configuration (REPORTED).
