# EB-03: First DeepSeek V4.1 Flash run: 1 XTX + host RAM, then + 1 MI50 helper
Status: kept (baseline) · Date: 2026-11-06
Code: in Gary's release commit. Flags: `--helper-device <mi50>`.

## What and why
- DeepSeek V4.1 Flash (2.25 bpw pack) on one XTX: 1,507 of 15,360 routed experts in VRAM, the rest (134.5 GB) in host RAM computed by the CPU lane. Then the same with one MI50 holding 2,964 experts.
- Target slice: the CPU lane's share of the decode step (27,087 of 61,200 expert picks went to the CPU in the alone arm) (MEASURED).

## Prediction
- No prediction was recorded before the run.
- Pre-registered: no.

## Correctness
- Teacher-forced quality: QA-01 (pass).
- A smoke prompt and a parity test were run at the time (REPORTED); their raw output is not in the extract (not reproduced).

## Timing
- Hardware: 1 × RX 7900 XTX (Gen4 x16) with the routed experts that do not fit in VRAM held in host RAM and run on the CPU ("CPU lane"); optionally 1 × MI50 32 GB helper (Gen4 x4). EPYC Zen 2 16-core, DDR4-2666. Stock XTX power settings.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus Gary's changes. Kernel version: not captured in the published extracts.
- 2,048-token prompt, 256 decoded tokens; 2 reps per arm, run sequentially (alone 1, 2, then helper 1, 2); fresh engine per rep.

## Verdict
- About +20 % decode from one MI50 (MEASURED). This is the 22.7 tok/s starting point of the write-up.
- Kept as the baseline.

## Reproduce
- Gary's release commit; one XTX with and without one MI50 helper. The bench script used for this card is not included in the release. About 20 GPU-min (two arms with a 134 GB RAM load each).

## Notes / caveats
- 2 sequential reps, not interleaved: treat the +20 % as indicative, not tight.
- Absolute numbers come from a private prompt set (not published); a re-run on a public text is pending. Ratios between arms of the same run are the comparable quantity.
- Headline card: a public-text re-run is planned (about 20 GPU-min).
