# NX-06: Fast MI50 helper round trip
Status: kept (opt-in; in every recommended environment) · Date: 2026-11-20
Code: in the fork's `flashnext-amd` commits. Flags: `STRATA_HELPER_FAST=1 STRATA_HELPER_GRAPH=1 STRATA_HELPER_THREADS=1`, plus `STRATA_HELPER_CPUS=<one CPU per helper>`.

## What and why
- Each helper launch used to be host-driven copies plus kernels, issued one helper after another by the host thread. The fast form follows the DeepSeek engine's helper transport: a fetch kernel reads the inputs straight from coherent host memory, a push kernel writes the rows back, a flag kernel signals completion (`_FAST`); the sequence is captured once and replayed as a graph (`_GRAPH`); and each helper has its own issue thread on its own CPU (`_THREADS`, `_CPUS`), so the four MI50s run concurrently.
- Only the transport changes; the expert kernels are the same.

## Prediction
- Expected a smaller helper wait; no numeric prediction recorded.
- Pre-registered: no (the repeat-exactness guard ran first).

## Correctness
- Repeat test first: 96 / 96 texts identical (MEASURED).
- Solo 256 tokens = one card; every run's texts at 1/2/4/8 users equal its own solo texts and the cycle-5 engine's: 8/8, 2/2, 4/4, 8/8 in all four runs (MEASURED).

## Timing
- Hardware: 2 × RX 7900 XTX 24 GB, 4 × Instinct MI50 16 GB (135 W cap), EPYC 7642 (48 cores), 256 GB DDR4-2666.
- Software: Strata v0.2.9 plus this fork's changes on ROCm 7.2 (the runtime in Strata's ROCm image). Kernel version: not captured in the published extracts.
- Workload: 8 prompts × 384 tokens, temperature 0, presence 0; UD-IQ4_XS; tp2 + 4 MI50; alternating B N B N.
