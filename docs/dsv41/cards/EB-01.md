# EB-01: gfx906 (MI50) expert helper inside the RDNA3 build
Status: kept · Date: 2026-11-06
Code: in the fork's release commit. Flags: helper device list on the command line (`--helper-device`); `STRATA_HIP_HELPER_ALLTU` (build).

## What and why
- An MI50 (gfx906) holds a share of the routed experts and computes them when the RX 7900 XTX (gfx1100) routes to them, inside one engine process. Needs both architectures compiled into the same build and a per-device kernel policy.
- Work was done first on Strata's main engine (Qwen3.8-Flash-Next) because it loads in seconds; DeepSeek V4.1 Flash followed the same day (EB-03).
- Target slice: decode time spent waiting on experts the XTX cannot hold; at small expert-cache sizes most picks miss VRAM (INFERRED).

## Prediction
- Six gate scripts were written before the first run: build, device discovery, parity, teacher-forced quality, and a decode A/B with an abort if the helper arm (b) is slower than XTX alone (a).
- Pre-registered: yes (gate scripts committed before the first run, same morning).
- Pass: b ≥ a on median decode, quality gate passes. Abort: b < a.

## Correctness
- Teacher-forced comparison over 511 positions, XTX alone vs XTX + MI50: passed (REPORTED) (raw comparison output not in the extract).
- Cross-device parity test of the expert kernels: passed (REPORTED).

## Timing
- Hardware: 1 × RX 7900 XTX + 1 × MI50 32 GB helper (link per run below); EPYC Zen 2 16-core, DDR4-2666; stock XTX power settings. Model: Qwen3.8-Flash-Next on Strata's main engine.
- Software: ROCm 7.14 on Linux; Strata v0.2.9 plus this fork's changes. Kernel version: not captured in the published extracts.
- Workload: private prompt, 256 decoded tokens, 8,192-token prefill per rep; speculative drafting on (Strata default).
- 5 reps per arm, arm a then arm b, fresh engine per arm; expert-cache size swept (auto / 5000 / 2500 / …).
- First runs that morning showed XTX junction 89–98 °C (HW-01); the matrices here ran after the cooling fix.

## Verdict
- The abort line never fired; the helper helped at every cache size. The gain grows as the cache shrinks, as expected when more picks miss VRAM (INFERRED).
- Kept; became the basis for every later MI50 card.

## Reproduce
- Fork release commit; build with the helper archs (`STRATA_HIP_HELPER_ALLTU=1`); run the decode A/B gate (`tools/dsv41/gates/gates.sh gate5`; see `tools/dsv41/gates/README.md`). About 5 GPU-min per cache size.

## Notes / caveats
- Rep-to-rep spread inside an arm is large (e.g. 45.1 → 64.0 tok/s across 5 reps of one arm, `ab-reps-x16.txt`) because drafting acceptance varies with what is generated. Medians of 5 hide this; later cards switched to a frozen multi-prompt set and per-step times (ME-01).
- Absolute numbers come from a private prompt set (not published); a re-run on a public text is pending. Ratios between arms of the same run are the comparable quantity.

Numbers are labelled MEASURED (read from a raw run file or a script-written summary), REPORTED (from a commit message or write-up at the time, not re-checked against raw output) or INFERRED (our own reading).
