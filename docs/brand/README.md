# YST brand files

The YST mark used on Gary's front page. Copied from YST's brand pack with no change to the drawing. The only change is
that colours are written as hex rather than `oklch()`, so that GitHub and older SVG renderers show them.

| file | what | colours |
|---|---|---|
| `mark.svg` | The mark, full colour, for light backgrounds | `#00566D` `#2C5A9D` `#754481` |
| `mark-slate.svg` | The mark, full colour reversed, for dark backgrounds | `#009EB6` `#8EB8F6` `#E6BDF0` |
| `yst-lockup-light.svg` | Lockup: mark left, lower-case `yst` wordmark, for light backgrounds | mark as above, wordmark `#101215` |
| `yst-lockup-dark.svg` | The same lockup for dark backgrounds | slate mark, wordmark `#F2F3F6` |

The lockups follow the brand pack's measurements. The mark is 65 × 40 at 40 px type with a 15 px gap, the wordmark is
IBM Plex Mono 500 (falling back to the system monospace), and one mark-height of clear space is built into the artwork
on all four sides. The one-colour cuts are for print only, so they are not included here.
