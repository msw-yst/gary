# NX-03: Batch self-commit
Status: kept (default under tensor parallel; recommended on one card) · Date: 2026-11-20, one-card A/B 2026-11-21
Code: in the fork's `flashnext-amd` commits. Flags: `STRATA_BATCH_SELF_COMMIT=1` (default on with `--tensor-parallel 2`; `=0` turns it off).

## What and why
- After each batch window a separate commit graph advanced every slot's state (2.7 ms at 4 rows, 5.1 at 8 under tp2; 2.6 / 5.6 on one card). A window with one row per slot can advance its rows itself.

## Prediction
- No numeric prediction was recorded before the run.
- Pre-registered: no.

## Correctness
- Exact: every prompt identical solo vs 2/4/8 users and against the base arm at every level; solo 256-token text = one card (MEASURED).

## Timing
- Hardware: 2 × RX 7900 XTX 24 GB, 4 × Instinct MI50 16 GB (135 W cap), EPYC 7642 (48 cores), 256 GB DDR4-2666.
- Software: Strata v0.2.9 plus this fork's changes on ROCm 7.2 (the runtime in Strata's ROCm image). Kernel version: not captured in the published extracts.
- Workload: 8 prompts × 384 tokens, temperature 0, presence 0; alternating base / self-commit pairs (another job was running on the machine during part of it, hence pairs).

## Verdict
- Kept. Default on under tensor parallel; set it on one-card servers and pool workers (every recommended environment in the README does).

## Reproduce
- Any layout in [README.md](../README.md#launch) with and without the switch.

## Notes / caveats
- ~1.3 ms of the commit graph's cost comes back as the in-window state advance under tp2.
- Absolute numbers come from a private prompt set (8 prompts, not published); ratios between arms of the same run are the comparable quantity.

Numbers are labelled MEASURED (read from a raw run file or a script-written summary), REPORTED (from a commit message or write-up at the time, not re-checked against raw output), ESTIMATE (our arithmetic) or INFERRED (our own reading).
