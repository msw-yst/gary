# Decode A/B: penalties in batch windows, B6 under TSUM (2026-11-21, data extract)

Sanitised extract behind cards NX-08 and NX-09. Layouts: S = XTX A + MI50 #1, #2, self-commit, MTP off; SM = S + MTP +
`STRATA_BATCH_MTP=1`; T = tp2 + 4 MI50. One server at a time; peaks XTX 64 C, MI50 63 C; no resets.

## Penalties in batch windows (now the default)

Before: `sample_rows` dropped every penalty and skipped greedy rows, so batched requests lost the model card's presence
penalty (1.5) and any penalty in the request body. After: the batch loop stages one history row per window row (the slot's
consumed tokens + its fed token or proposal) and samples penalised rows exactly as the solo window does.

| Check | Before | After |
|---|---|---|
| batched == solo, temperature 0 + presence 1.5 | 0/8 | 8/8 (and 4/4) on S, T and SM |
| batched == solo, model-card set (temperature 0.7, top_p 0.8, top_k 20, presence 1.5, seeded) | - | 8/8 |
| batched == solo, body overrides (presence, frequency, repetition, penalty_last_n) | - | 8/8 |
| solo texts | - | unchanged |
| S 8-user aggregate | 122-124 tok/s | 122-124 tok/s (within noise) |

`logit_bias` was already refused under `--batch`. With penalties on, tp2's solo text differs from one card's (equal at presence
0); pre-existing, not investigated.

## B6 under TSUM (`STRATA_B6_MMVQ_ROWS=1`, opt-in)

The B6 kernel gets the TSUM epilogue (bitwise the same sums) and, under TSUM, takes calls of >= 7 columns
(`STRATA_B6_MMVQ_MIN`; at 4-6 columns it was neutral except the tp2 gate half, up to 1.35x slower).

Kernel bench (XTX, 8 rows, today's TSUM kernel -> B6 + TSUM): lm head 2,274 -> 1,654 us; qkv 103 -> 69 us; gate 66 -> 44 us;
attention q 111 -> 85 us. Bitwise equal to the default and to single-column calls in every case. Trace on T at 8 users: the
Q6_K 8-row calls per window on card 0 6.75 -> 4.55 ms; lm head 270 -> 444 GB/s; qkv half 238 -> 356 GB/s.

Servers, aggregate tok/s all active, mean of two alternating runs:

| Layout | Users | Before | After | Change |
|---|---|---|---|---|
| S | 8 | 121.1 | 129.1 | +6.6 % |
| SM | 8 | 107.2 | 114.2 | +6.4 % |
| SM | 4 (~7-8 rows a window) | 107.5 | 114.2 | +6.3 % |
| T | 8 | 161.9 | 169.4 | +4.6 % |
| all | 1-2 | - | - | no change |

Reference hashes unchanged (`a7ae6623797f17fe` on S and T, `da29bc7d5a0ba433` on SM in this environment); batched == solo 8/8.

Tried and dropped: one warp per row group running the exact layout's four partial loops in sequence: exact but 1.1-3x slower.
