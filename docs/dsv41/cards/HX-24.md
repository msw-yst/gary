# HX-24: MI50 kernel switches: per-group kernel choice, an LDS sign table, DPP reductions
Status: kept (`DS4_G906_SGNLDS` in the build-13 code, off when served); per-group choice and DPP dropped · Date: 2026-11-12
Code: in the fork's release commit. Flags: `DS4_G906_SGNLDS=1` (kept in the code, default off); `DS4_G906_PERGROUP=1`, `DS4_G906_DPP=1` (dropped).

## What and why
- After HX-23, a review of other MI50 projects (one MIT-licensed, whose idea is used with notice; one AGPL, ideas only) ranked ten kernel ideas. Three were cheap enough to try at once, each behind its own flag:
  - `PERGROUP`: choose the gfx906 kernel per row group instead of per launch, to keep the faster gfx906 path for one-entry groups inside a mixed launch (the loss seen with `DS4_G906_NEMAX=4`, SV-09);
  - `SGNLDS`: read the IQ2/IQ3 sign masks from a 128-entry table in LDS instead of computing them;
  - `DPP`: cross-lane reductions with DPP / swizzle instructions instead of shuffles.
- Each went to a single-card kernel bench first; only a bench winner went to the engine.

## Prediction
- Bench: PERGROUP −14 to −27 µs a verify window on one-entry groups; SGNLDS −1.9 to −4.8 µs a one-row window; DPP −0.3 to −1.2 µs.
- Engine (SGNLDS): B1 −0.13 to −0.05 ms a token (central −0.09); production −0.10 to −0.02 (central −0.06). Pre-registered: yes, for both steps, before the runs.

## Correctness
- Bench: every arm bit-identical to the old kernels (REPORTED). Engine: 4 identity lines IDENTICAL (unset vs the base; on vs off on decode, drafter decode and batch test), with the new kernel engaged (388 launches) (MEASURED).

## Timing
- Hardware: 4 × RX 7900 XTX (XTX #1–3 Gen4 x16, XTX #4 Gen4 x8) + 4 × MI50 32 GB at 135 W (Gen4 x4 each). XTX at minimum power cap with −50 mV. MI50 DPM `high` (CP-03). The bench ran on one production MI50.
- Software: ROCm 7.14 on Linux; build 12pf plus the flags. OFF / ON / placebo, 6 reps each, interleaved.

## Verdict
- **SGNLDS: exact, −0.11 ms a token in a single session, nothing in serving.** It speeds only one-row MI50 windows; with the drafter on, production windows are mostly 2–4 rows (FG-08's 5.1 % one-row share). It is in the build-13 code and gated for identity, but not in the served environment.
- **PERGROUP: dropped.** The loss it targeted was never from mixing paths in one launch: the per-launch rule already picks a well-tuned kernel for groups with two or more entries, and per-group choice sent those to a slower body [I].
- **DPP: no effect.** The compiler probably already lowers the shuffles to DPP on gfx906 (not checked in the machine code).
- The production levers on the MI50 side are the multi-row windows; HX-25 tried them.

## Reproduce
- No published run: the code is in the release commit; a scripted public re-run has not been prepared for this card.
